# DOMAIN-GOV-001 — Capability Reuse Checklist

Antes de desenvolver, confirmar e anexar evidência:

- [ ] Existe capacidade equivalente?
- [ ] Existe contrato reutilizável?
- [ ] Existe serviço corporativo?
- [ ] Existe adapter possível?
- [ ] Existe domínio proprietário?
- [ ] Registries certificados foram consultados?
- [ ] Capacidades horizontais da plataforma foram consultadas?
- [ ] RBAC e segurança existentes podem ser reutilizados?
- [ ] Existe integração sem alterar a baseline?

## Caminho selecionado

Selecionar exatamente um:

- capacidade existente;
- contrato existente;
- serviço corporativo;
- adapter;
- extensão pelo domínio proprietário;
- exceção greenfield explicitamente aprovada.

Nenhum checklist é válido sem referências de evidência. Exceção greenfield exige aprovação arquitetural extraordinária e não pode ser inferida pela ausência de pesquisa.
